# 벤치에서 발롱까지 : 커스텀 에디터 & 구단 감독 에디션

원작 [kickru.com](https://kickru.com)의 축구선수 커리어 시뮬레이터를 바탕으로 아래 확장 기능을 탑재한 설치형 / 웹 배포판입니다.

## 주요 기능

1. **⚡ 실시간 선수 스탯 · 나이 · 커리어 에디터 (`F2` / `Alt+E`)**
   - 10종 세부 능력치(0~100), OVR, 잠재력, 성장 곡선, 내구성 실시간 조절
   - 시작 나이(16~45세), 시즌 연도, 진로(고교/대학/유스/프로), 국적, 신체, 주발/약발, 주장 완장, 계약/연봉/자산, 병역 면제, 즉시 이적 및 오퍼 생성
   - **상점 무제한 구매 & 34종 전 아이템 상시 해금**

2. **👔 구단 감독 모드 (`감독 모드`) & FM 3D/2D 라이브 매치 엔진**
   - 2,155개 실존 구단 & 전 세계 리그(승격/강등, 국내 컵, 대륙 대항전)
   - 포메이션, 전술, 유스 아카데미, 스카우팅, 5대 시설 투자, 구단 치트
   - 3D/2D 다중 카메라(`3D TV`, `3D 줌`, `3D 골대`, `2D 클래식`) 라이브 매치, 터치라인 외침, 하프타임 라커룸 토크, 실시간 5인 교체

3. **💾 로컬 폴더 저장 & 불러오기 (`Alt+S` / `💾 저장·불러오기`)**
   - **앱 `saves/` 폴더 자동/수동 저장**: 로컬 앱 실행 시 `saves/*.json`에 선수/구단 커리어를 각각 또는 통합 백업으로 저장하고, 언제든 1클릭으로 불러와 이어하기 가능
   - **PC 폴더 직접 연결 (GitHub Pages 지원)**: Chrome/Edge의 File System Access API(`내 PC 저장 폴더 연결`)로 내 PC의 원하는 폴더에 직접 저장·로드
   - **`.json` 파일 내보내기 / 가져오기** 범용 지원

4. **📲 설치형 실행 방법**
   - **Windows 바탕화면 바로가기 설치**: `설치하기_바탕화면_바로가기.bat` 실행 시 바탕화면에 단독 앱 아이콘 생성 (`앱모드_실행.bat`으로 창 모드 실행)
   - **웹 브라우저 PWA 설치**: 주소창의 `앱 설치` 또는 상단 `📲 앱 설치` 버튼 클릭
   - **Electron 데스크톱 패키징**: `npm install && npm run dist` 실행 시 Windows 설치형(`.exe`) 빌드 가능
